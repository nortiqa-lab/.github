# Runbook — Cold start any agent

Use when a new chat opens with almost no context.

```
1. Read AGENTS.md
2. Read agents/SHARED_RULES.md + agents/AUTONOMY.md
3. Read agents/BOOTSTRAP.md if Notion unavailable
4. Read role sheet agents/roles/<NL-*.md>
5. Read newest docs/shared-ai-memory/handoffs/*
6. git status --short
7. Execute solo loop from prompt
8. Write new handoff before finishing
```

Default role if unspecified: **NL-ORCH**.
